## Steps to Get the Flag

1. **Unpack the UPX binary:**
```bash
upx -d --force unpackme-upx
```

2. **Find the correct number using disassembly:**
```bash
objdump -d unpackme-upx | grep -A5 -B5 "cmp"
```
→ Found `cmp $0xb83cb, %eax` meaning the number is `0xb83cb` = **754635** in decimal

3. **Run the binary with the correct number:**
```bash
./unpackme-upx
```
Enter `754635` when prompted

4. **The flag is printed!** 🚩


Use the lldb to find the number, there are comparing the input to the number
at a specific address, you need to read it
